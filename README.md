# Seng Soon Air-Cond & Refrigerator Landing Page

Static landing page for Seng Soon Air-Cond & Refrigerator Servicing, a local aircond shop serving the Klang and Kapar area in Selangor, Malaysia.

## Features

- Responsive single-page layout
- English, Malay, and Chinese language support
- WhatsApp-first contact flow
- Google Maps shop listing link and embedded map
- LocalBusiness and FAQ structured data
- Google Search Console verification file
- Sitemap and robots.txt
- Local brand/logo assets and favicons
- Open Graph and Twitter preview image

## Tech Stack

- HTML
- CSS
- JavaScript
- Cloudflare Pages

## Deployment

The site is designed to be deployed as a static site on Cloudflare Pages.

Canonical URL:

```txt
https://sengsoonaircond.pages.dev/
```

If a custom domain is added later, update the canonical URL, sitemap URL, structured data URL, and Open Graph image URL.
